# TGPulse-Next Libretro 0.1.0.1 — Global source Gain settings

This experimental Model 1 preview restores global source Gain settings,
following the audio option scope used by SM2-Emu Libretro and Supermodel.
The upstream snapshot is unchanged; the final version component is the port
revision. This remains the interim M1 core, pending real Tiny selection.

## Changes from 0.1.0.0

- MultiPCM 1, MultiPCM 2, FM (YM3438) and DSB (MPEG) gains use four global
  Core Option keys shared by Model 1 parents and clones.
- Each source defaults to Auto, preserving the standalone reference mix:
  50%, 50%, 30% and 100% respectively.
- Mute, Auto and 0–100% in 10% steps remain available with immediate updates.
  DSB visibility still follows the actual fitted board.
- Removed set-qualified Gain definitions and labels from both modern and
  legacy Core Options. Load-time and live updates use the same global keys.
- Updated the single roadmap, frontend adaptation notes and audio procedure.

## Updating saved options

Old per-set Gain keys are ignored. Previous global Gain selections may become
active again if they remain in your frontend options file. To start with the
reference mix, select Auto for each source and save core options. With
RetroArch closed, obsolete source Gain/Mute entries may also be removed from
this core's options files after saving a backup. Keep NVRAM and unrelated
settings. No personal option files are rewritten by the core.

## Packages and verification

Native packages: Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows
x86_64. Each ZIP contains the M1 core, matching metadata, installation guide,
source/build information, project/dependency licenses and internal checksums.
Release SHA256SUMS covers all five ZIPs. No ROMs, saves or personal settings
are included.

Publication requires all five native CI builds, machine/adapter checks,
25 ABI exports, dependency and empty-lifecycle checks, and full package,
version, source-revision, license and checksum validation. The 47 adapter
regressions cover global modern/legacy registration, Auto fallback,
Mute/numeric parsing and conditional DSB visibility.

## Requirements and limits

The core remains an experimental Model 1 Development build. Linux packages
use Ubuntu 24.04; older glibc compatibility is not guaranteed. macOS requires
13 or newer; use Vulkan/MoltenVK there. OpenGL requires desktop 4.3 or GLES 3.1.
NetMerc remains excluded from NVRAM management because it cannot start.
Gameplay, listening and physical controller acceptance remain user-run;
CI and packaging gates do not establish that evidence.
