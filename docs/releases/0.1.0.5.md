# TGPulse-Next Libretro 0.1.0.5 — Model 1 Preview

This experimental Model 1 single system build uses one Libretro-compatible
release recipe for local builds, GitHub CI and Libretro GitLab jobs.

## Changes From 0.1.0.3

- `Makefile.libretro` is the shared release build entry point for Linux
  x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64. GitHub now
  builds, checks and packages its public output; Libretro GitLab jobs use
  the official Rust templates and invoke that same recipe.
- Windows uses GNU/MinGW with static runtimes, matching the Libretro template.
  The static link group includes MinGW TLS support required by newer GNU
  C++ and winpthread archives.
  Linux retains static C++ linkage. macOS links with the public `@rpath`
  library name and signs/verifies native builds.
- Public packages use Core Name **TGPulse-Next: Model 1** and Core Label
  **Sega - Model 1 (TGPulse-Next)**. The local RetroArch installation retains
  its separate Development name and `tgpulse_next_dev_m1_libretro` filename.
- FM (YM3438) Gain still defaults to Auto, which now selects 90%. Explicit
  percentage selections are unchanged; the standalone FM mix remains 30%.
- Repository documentation and the prepared Libretro registration proposal
  describe the shared build contract and public metadata.

## Packages And Verification

The release workflow requires all five native build/test/artifact/package jobs
before publication. Every platform ZIP includes the Model 1 core, matching
`.info`, installation guide, source/build information, licenses and internal
SHA256SUMS. Release SHA256SUMS covers all five ZIPs. No ROMs, personal settings
or saves are distributed.

The Libretro-owned GitLab pipeline and ecosystem registration remain pending;
this release verifies the shared recipe through this repository's GitHub CI.
Existing frontend and controller evidence is retained. Publication does not
claim new gameplay, device or rumble/drift acceptance. Sega NetMerc remains
experimental, and Save States remain unavailable while a linked COMM board
is fitted. Machine Save State format remains 5; Save RAM is unchanged.
