# TGPulse-Next Libretro 0.1.0.2 — Model 1 single system build

This experimental Model 1 preview selects only Model 1 machine components and
required shared devices at compile time. The upstream snapshot is unchanged;
the final version component is the port revision.

## Changes from 0.1.0.1

- Model 1 and Model 2 have separate Cargo machine features. The M1 adapter
  selects Model 1 only; the standalone still selects both systems by default.
- Model 2 machines, SCSP, i960, MB86235, SHARC and the combined debugger are
  excluded from the M1 library. Shared devices needed by Model 1 are retained.
- The embedded catalogue contains the ten Model 1 sets, selected from the
  unchanged authoritative source database at build time.
- Packages include only licenses from the adapter's actual dependency graph.
  BUILD_INFO records the compiled scope; ABI and package gates verify it.
- CI independently checks Model 1, Model 2-only and combined library builds,
  avoiding Cargo feature unification in the M1 adapter build.

Core names, filenames, controls, NVRAM and global source Gain options remain
compatible. Source Gains default to Auto. No configuration migration is needed.
The Model 2 and combined Libretro adapters remain future work.

## Verification

Local Model 1, Model 2-only, combined library and adapter tests passed. Across
nine bootable Model 1 sets, 120-frame software output, audio, Save RAM and
serialized state matched the previous build exactly. Previous states imported
successfully and continued identically. The standalone build check, isolated
RetroArch Vulkan run and Development installation also passed.

The local macOS binary decreased from 3,557,184 to 3,422,352 bytes (3.79%). This
is a build-scope measurement, not a gameplay performance claim.

## Packages and requirements

Native packages: Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows
x86_64. Each ZIP contains the M1 core, matching metadata, installation guide,
source/build information, project/dependency licenses and internal checksums.
Release SHA256SUMS covers all five ZIPs. No ROMs, saves or personal settings
are included. Publication requires all five native build and package gates.

The core remains an experimental Model 1 Development build. Linux packages
use Ubuntu 24.04; older glibc compatibility is not guaranteed. macOS requires
13 or newer; use Vulkan/MoltenVK there. OpenGL requires desktop 4.3 or GLES 3.1.
NetMerc remains excluded from NVRAM management because it cannot start.
Gameplay, listening and physical controller acceptance remain user-run;
CI and package checks establish separate build/publication evidence.
