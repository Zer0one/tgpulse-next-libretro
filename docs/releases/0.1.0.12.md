# TGPulse-Next Libretro 0.1.0.12 — Model 1 Preview

## Changes From 0.1.0.11

- Default Widescreen Mode to Disabled. On hardware renderers, Expand 3D View Only and Expand 3D View + Stretch 2D report 16:9 when Aspect Ratio is Auto or 16:9; explicit 4:3 suppresses expansion.
- Apply Widescreen Mode changes when returning to the game, without a machine reset or content reload. Fix the cached selection that could leave the previous expanded view active after selecting Disabled or using Restart.
- Preserve native widescreen games, their monitor NVRAM and manual aspect overrides. Keep Software rendering unchanged. Disabled with explicit 16:9 stretches the original image; the second expansion mode stretches both native 2D layers.
- Align Aspect Ratio/Widescreen help and verification tools with the reviewed behavior. Existing GPU rendering, projection and shaders are retained. Renderer and Supersampling still require content reload.

## Upgrade Notes

Install the matching core and `.info`, then reload the core. Core Name **TGPulse-Next-M1**, label, filenames, Save RAM layout and machine Save State format 5 are unchanged.

The saved `stretch` value now appears as Disabled and becomes the default for new configurations. Existing explicit expansion selections remain valid and may now select wide presentation with Aspect Ratio Auto. Select 4:3 to suppress expansion without changing the stored Widescreen Mode.

## Packages And Verification

The shared Libretro recipe builds Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64 GNU. Publication requires native tests, ABI/Model 1 scope checks, exact source revision, license inventories and package checksums.

The preceding implementation phase passed 93 adapter checks, 36 actual-core geometry/Save RAM cases and the 89-registration/44-key menu audit. A real macOS RetroArch Vulkan VF session verified all three Widescreen Mode selections, return to Disabled, explicit 4:3 suppression and Disabled + 16:9 on actual 3D scenes, without reset. These results are retained; they do not establish new OpenGL/GLES runtime, other-platform gameplay or physical-controller acceptance. No ROMs, personal settings, saves or generated recordings are distributed.
