# TGPulse-Next Libretro 0.1.0.10 — Model 1 Preview

## Changes From 0.1.0.9

- Make NVRAM Settings the master switch for Automatic Network Settings. An active preset maintains its managed operator selectors; Disabled preserves manual values. Publish selector changes after the core callback lock is released to avoid a VR startup freeze.
- Apply Linked Cabinets changes when returning to the game. Fit or remove the native COMM board before applying the selected operator role and before the next emulated frame, preserving Save RAM. Changed persisted NVRAM values trigger the existing automatic machine reset.
- Retain an open Netplay lobby through topology changes, permit clients to join during setup, and tolerate peers temporarily using different cabinet totals while they resume. A different game/set identity remains an error.
- Remove the early Netpacket availability notice, which could appear before a working session was established. Update the Linked Cabinets menu text to match Resume behavior.

## Upgrade Notes

Install the matching `tgpulse_next_m1_libretro` core and `.info` on every Netplay participant. The public Core Name **TGPulse-Next-M1**, Core Label **Sega - Model 1 (TGPulse-Next)**, option keys, Save RAM layout and machine Save State format 5 remain unchanged. Open RetroArch sessions must reload the core to use the new binary.

## Packages And Verification

The five-platform GitHub matrix builds Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64 GNU. Publication requires native tests, ABI and Model 1 scope checks, source revision, license inventory and package checksums. Local verification covered 86 adapter tests, the exact option-change Resume sequence through the Libretro ABI, and a separate two-instance RetroArch session that reached game-created COMM online on both cabinets. The two-instance run started with options already selected. No ROMs, settings or saves are distributed.
