# TGPulse-Next Libretro 0.1.0.8 — Model 1 Preview

## Changes From 0.1.0.7

- Rename the runtime `library_name` and metadata `corename` to
  **TGPulse-Next-M1**. Core Label **Sega - Model 1 (TGPulse-Next)** and the
  `tgpulse_next_m1_libretro` binary filename are unchanged.
- Adapt the local macOS installer to copy settings, remaps, saves and states
  from `TGPulse-Next - Model 1` and the earlier `TGPulse-Next: Model 1` identity.
  Prefer files from the most recent identity, preserve originals and never
  overwrite existing destination files.

## Upgrade Notes

Close RetroArch before installing. Copy previous core-named configuration,
remap, save and state directories to `TGPulse-Next-M1`, including renamed
core-level `.opt`, `.cfg` and `.rmp` filenames where present. Preserve originals
and existing destination files. The repository's macOS installer handles the
default local paths. Custom directory layouts require the equivalent manual
copy. Refresh the Core Info cache and restart RetroArch. Netplay participants
should all upgrade because the advertised core name has changed.

There are no emulation, input, rendering or audio changes in this release.
The Netpacket protocol remains `TGPulse-Next Model 1 M1COMM v1`;
machine Save State format remains 5, and Save RAM layout and Core Option keys
are unchanged. The existing performance and Netplay fixes are retained.

## Packages And Verification

The unchanged five-platform native GitHub matrix builds and checks Linux
x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64 GNU. Publication
requires ABI/runtime-metadata identity, Model 1 scope, source revision, license
and checksum gates. No ROMs, personal settings or saves are distributed.
These gates are separate from gameplay and physical-controller testing.
