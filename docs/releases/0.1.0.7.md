# TGPulse-Next Libretro 0.1.0.7 — Model 1 Preview

## Changes From 0.1.0.6

- Use **TGPulse-Next - Model 1** consistently for the runtime Core Name and
  distributed metadata. This avoids the colon in core-named filesystem paths
  and preserves a distinct identity for future Model 2 builds.
- Align runtime and metadata identities so RetroArch can discover the installed
  core when joining a Netplay lobby. Keep Core Label
  **Sega - Model 1 (TGPulse-Next)** and the `tgpulse_next_m1_libretro` filename.
- Increase the bounded Netpacket receive queue and drain it according to native
  COMM receive capacity, preserving packet order and emulated time during bursts.
- Preserve previous local macOS files and copy settings, remaps, saves and states
  from the former core identity without overwriting existing destination files.

## Upgrade Notes

Close RetroArch before installing. Copy any directories named
`TGPulse-Next: Model 1` to `TGPulse-Next - Model 1` in your configured settings,
remap, save and state locations. Preserve originals and existing destination
files. The repository's macOS installer handles the default local paths.
Refresh the Core Info cache and restart RetroArch. All Netplay participants
should upgrade because the advertised name has changed. After a participant
disconnects from a linked-cabinet session, reload the game on every cabinet.

The Netpacket protocol remains `TGPulse-Next Model 1 M1COMM v1`.
Machine Save State format remains 5; Save RAM layout and Core Option keys are
unchanged. Existing performance improvements are retained. Sega NetMerc remains
experimental, and Save States remain unavailable while a COMM board is fitted.

## Packages And Verification

The existing native GitHub matrix builds and checks Linux x86_64/ARM64,
macOS Apple Silicon/Intel and Windows x86_64 GNU. Publication requires all five
packages to pass ABI, runtime/metadata identity, Model 1 scope, source revision,
license and checksum gates. No ROMs, personal settings or saves are distributed.
These release gates are separate from gameplay and physical-controller testing.
