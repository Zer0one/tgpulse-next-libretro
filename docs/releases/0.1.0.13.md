# TGPulse-Next Libretro 0.1.0.13 — Model 1

## Changes From 0.1.0.12

- Add direct display-list polygons with native screen-space projection,
  color/luminosity translation, depth sorting and moire handling. Suppress
  degenerate direct moire points, following current MAME references.
- Composite above-HUD objects using MAME’s brightness stencil in Software,
  Vulkan and OpenGL/GLES. Keep frontend Timing/Diagnostic UI above the scene
  and retain the shared standalone renderer path.
- Clip Software wireframe endpoints before Bresenham traversal and bound
  malformed direct display-list walks.
- Show one Linked Cabinets local choice, **1 Cabinet / Disabled**. Accept
  `0`/`1` as parser aliases only; likewise accept role aliases `l`/`s` without
  exposing duplicate Live choices. Defaults and native topology remain explicit.
- Default Auto Network Role Settings to **Disabled** (`-1`), including missing
  or invalid selections. Explicit valid saved roles keep their meaning.
- Rename the manual override switch to **NVRAM Settings (Service Menu)** and
  align dependent help/notifications without changing its key or saved values.

## Compatibility

Public identity **TGPulse-Next-M1**, core filenames, Save RAM layout and machine
Save State format 5 remain unchanged. Reload the core after installing the
matching core/info pair. Existing manual service-menu choices remain effective
when role automation and NVRAM overrides are disabled. AINS initialization and
valid-save precedence are unchanged; no speculative startup-credit patch is
included in this release.

## Packages And Verification

One shared Makefile builds Linux x86_64/ARM64, macOS Apple Silicon/Intel and
Windows x86_64 GNU. The release workflow requires native tests, ABI/dependency/
Model 1 scope checks, exact source revisions, licenses and package checksums.

Local implementation verification includes 254 Model 1 tests (one existing
ignored), 94 adapter tests, complete modern/legacy menu registration checks,
nine-set old/new video/PCM/Save RAM/state comparison, macOS RetroArch Vulkan
and Linux EGL OpenGL/GLES/Software runs. The unchanged real-game captures are
regression evidence; synthetic cases establish the new command behavior.
See the direct/HUD and wireframe reports for coverage limits. CI and bounded
API tests do not establish exhaustive gameplay or physical-controller acceptance.
No ROMs, personal saves, settings or diagnostic recordings are distributed.
