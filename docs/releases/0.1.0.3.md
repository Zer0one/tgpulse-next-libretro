# TGPulse-Next Libretro 0.1.0.3 — Model 1 integration candidate

This experimental Model 1 single system build retains the compiled Model 1
component scope introduced in 0.1.0.2. The upstream snapshot has been
selectively aligned with TGPulse-Next 0.1.0.1 while keeping standalone and
Libretro host ownership separate. The final public version component is the
Libretro port revision; Cargo remains at 0.1.0.

## Changes from 0.1.0.2

- Sega NetMerc machine integration adds the reviewed DSP, I/O, audio, tracking,
  LCD and complete machine-state changes. The finite arithmetic correction
  remains conditional on NetMerc. NetMerc remains experimental.
- A dedicated `Special: Sega NetMerc` controller profile supports native
  Trigger/Thumb/Holder actions and virtual Calibrate/Recenter commands. P1 MVD
  can use the right stick or frontend sensors, with three-second calibration,
  gravity stabilization, manual recentering and adjustable stationary drift
  compensation (50% default). Optional bounded CSV capture supports physical
  controller analysis.
- NetMerc cabinet rumble uses the final native motor latch and RetroArch's
  existing rumble gain. The Gamepad Rumble Core Option remains Enabled by
  default. Physical motor and sensor interaction requires controller testing.
- NetMerc's complete operator-setting campaign adds reviewed Automatic Initial
  NVRAM and NVRAM Settings selectors. A valid frontend save takes precedence;
  the optional `netmerc_nvram.bin` is used only when initial data is required.
  Initial calibration and bookkeeping fixes are applied only in that path.
- NetMerc audio donor selection uses game ZIPs beside `netmerc.zip`; fallback,
  procedural and incomplete-original modes report conditional notices. The
  optional HD44780 diagnostic LCD supports full or half size and optional BIOS.
- The NetMerc City graphics workaround is a live, title-specific Video option.
  General Core Options remain visible; per-set NVRAM and linked-cabinet
  selectors retain their approved applicability rules.
- Widescreen Hack defaults to Expand 3D View Only for games without native
  widescreen support. Supersampling works on Vulkan/OpenGL/GLES. Timing-overlay
  alpha, position and LCD overlap behavior have been corrected.
- Wing War and Wing War R360 Throttle Up now lowers the cabinet ADC. The right
  stick keeps its Up/Down bindings; R2/L2 now bind Up/Down respectively, so
  each trigger retains its prior physical response. Star Wars Arcade is unchanged.
- Model 1 machine Save States use format 5. Old format states are rejected
  without migration; existing Save RAM remains separate. Current documentation
  and Core Option descriptions reflect the implemented behavior.

## Installation and content

Each platform package will include its Model 1 core, matching `.info`,
installation guide, source/build information, project/dependency licenses and
internal SHA256SUMS. No ROMs, saves or personal settings are included. Place a
complete game ZIP in your content library. Donor game ZIPs for NetMerc must be
beside `netmerc.zip`. Optional `hd44780.zip` and game-selected I/O firmware are
searched in `system/tgpulse-next/`, beside the game and then in the game ZIP.

The Core Name remains **TGPulse-Next: Model 1 Development** and the Core Label
remains **Sega - Model 1 (TGPulse-Next Development)**. The local Development
installation uses the separate `tgpulse_next_dev_m1_libretro` filename.

## Verification boundary

Before publication, validate native Linux x86_64/ARM64, macOS Apple Silicon/
Intel and Windows x86_64 packages from one fixed source revision, with matching
core/info version, ABI, component-scope, licenses, dependency and checksum gates.
The local source audit, tests and macOS Development build are separate from
these candidate-package gates. Batocera and Windows RetroArch observations will
be reported as frontend evidence, not inferred from successful compilation.
Physical-controller feel, sensor/rumble coupling and broad gameplay remain
user-run checks.
