# TGPulse-Next Libretro 0.1.0.9 — Model 1 Preview

## Changes From 0.1.0.8

- Add **Automatic Network Settings** directly below each supported title's **Linked Cabinets** option. VR/VFormula default to Red (Master), provide seven distinct Slave car colors, and offer a Live relay with the default Red identity. Wing War variants offer Master and Slave.
- Apply the selected native role and identity to the existing reviewed operator fields. With Linked Cabinets OFF, active automation restores those fields to offline defaults. **Disabled** preserves existing fields, including when Linked Cabinets is switched OFF.
- Keep NVRAM Settings options synchronized with automatically selected values. A changed persisted value resets the machine so firmware reads it. Reload all participating cabinets after network topology or role changes.

## Upgrade Notes

Use the matching `tgpulse_next_m1_libretro` core and metadata on every Netplay participant. Core Name **TGPulse-Next-M1**, Core Label **Sega - Model 1 (TGPulse-Next)**, option keys, Save RAM layout and machine Save State format 5 are unchanged from 0.1.0.8.

## Packages And Verification

The five-platform GitHub matrix builds Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64 GNU. Publication requires native tests, ABI and Model 1 scope checks, source revision, license inventory and package checksums. These are separate from gameplay and physical-controller trials. No ROMs, settings or saves are distributed.
