# TGPulse-Next Libretro 0.1.0.11 — Model 1 Preview

## Changes From 0.1.0.10

- Adopt the two-option network convention: Linked Cabinets controls COMM topology; Auto Network Role Settings independently applies native role/identity, including when NVRAM Settings is disabled. Hidden managed selectors track the applied values and return to manual management when automation is disabled.
- Preserve pending option edits across paused-menu visibility/profile callbacks, so effective NVRAM, role and topology changes trigger the intended automatic machine reset. Retain lobby callbacks and connected clients through machine reconfiguration.
- Align option descriptions and functional menu groups. Add the global Controller Profile Type selector; use L3 Service / R3 Test while preserving historical controller IDs and existing remaps.
- Default new configurations to 60 Hz; retain explicit native timing selections. Canonical source Gain Mute values use `0`, with readable legacy aliases and an optional backed-up migration tool.
- Reverse Sega NetMerc sensor Roll polarity without changing the other axes or right-stick bindings. Adapt VR/Formula synthetic cornering rumble to frontend steering travel with a 5% onset; preserve standalone behavior and native effects.
- Add reset/audio recovery checks and update reference, network, menu and reuse documentation. Repository work and release tags follow `main` unless explicitly requested otherwise.

## Upgrade Notes

Install the matching core and `.info` on every Netplay participant, then reload the core. Public names, filenames, Save RAM layout and machine Save State format 5 are unchanged.

The former textual network-role tokens are superseded by numeric native-role identities. Review saved network choices after upgrade: Linked Cabinets Disabled and ANRS No Link / Stand Alone are the local-play defaults. Topology never silently changes an independently selected native role; a disconnected Slave/Live configuration can retain native missing-link behavior. Existing remaps are preserved; review Service/Test assignments if using custom mappings.

## Packages And Verification

The five-platform matrix builds Linux x86_64/ARM64, macOS Apple Silicon/Intel and Windows x86_64 GNU through the shared Libretro recipe. Publication requires native tests, ABI/Model 1 scope checks, license and source inventories, and checksums.

Local evidence includes 93 adapter tests; ten-set network authority/handover and retained-lobby lifecycle checks; eight native/60 Hz PCM reset cases totaling 30,000 frames; and a separate 120-second Vulkan/CoreAudio3 RetroArch recording through two native UI resets. No persistent audio-reset stall was reproduced. Recorded PCM is not subjective listening acceptance or a new two-peer gameplay qualification. No ROMs, personal configurations, saves or generated test recordings are distributed.
