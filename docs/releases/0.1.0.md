# First Model 1 preview

The first TGPulse-Next Libretro release provides an independent, experimental
Sega Model 1 core. This is the current interim M1 build; it is not yet the
component-selected Model 1 Tiny core. Model 2 and the combined core are planned.

## Highlights

- Software, frontend-owned Vulkan and OpenGL/GLES rendering, widescreen modes
  and 1–4x supersampling.
- Native timing plus optional 60 Hz timing, per-game source audio gains,
  master volume and timing/FPS overlay.
- Title-aware RetroPad profiles, distinct Star Wars Arcade Pilot/Gunner ports,
  driving analog ranges/response and VR-family rumble.
- Frontend Save RAM and Save States, automatic initial NVRAM and reviewed
  operator settings for nine independently documented parent/clone sets.
- Experimental linked cabinets through Libretro Netpacket, preserving native
  Model 1 COMM roles; Save States are disabled while COMM is fitted.
- Optional in-memory repair of the hash-identified 315-5711 bad dump.

## Packages

Native builds: Linux x86_64, Linux ARM64, macOS Apple Silicon, macOS Intel and
Windows x86_64. Each ZIP contains the M1 core, matching `.info`, installation
guide, source/build information, project/dependency license texts and internal
checksums. The release's `SHA256SUMS` verifies the five ZIPs. No external system
database is needed; no ROMs or user saves are included.

Core Name: **TGPulse-Next: Model 1 Development**.
Core Label: **Sega - Model 1 (TGPulse-Next Development)**.

## Requirements and limits

Linux packages are built on Ubuntu 24.04; older glibc compatibility is not
guaranteed. macOS targets version 13 or newer. Windows uses static C/C++
runtimes. OpenGL needs desktop 4.3 or GLES 3.1; use Vulkan/MoltenVK on macOS.

NetMerc cannot currently start and remains excluded from NVRAM management.
Real Model 1 Tiny selection is pending. Physical controller, broad gameplay
and distributed race/dogfight acceptance remain user-run.

## Verification

Publication requires all five native CI builds, machine/adapter unit checks,
25 ABI exports, dependency checks, three no-content lifecycle cycles and full
package/version/source/license/checksum validation. CI checks do not establish
real gameplay or controller behavior.

The existing macOS/Linux frontend evidence is documented in the repository.
The acquisition campaign covers nine sets, 110 fields and 953 saved/reloaded
discrete values, with four calibrated Wing War ranges. The reviewed workbook
selects 39 configurable fields. Raw captures are retained locally; CI audits
committed YAML and documentary screenshot coverage without ROMs or raw saves.
