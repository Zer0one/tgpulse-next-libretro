# TGPulse-Next Libretro 0.1.0.6 — Model 1 Preview

This preview publishes the retained Model 1 performance improvements through
one shared Libretro build recipe and the existing five-platform matrix.

## Changes From 0.1.0.5

- Group visible tilemap spans and mask blocks, with decoded tile-row caching
  shared by standalone and Libretro Software/Vulkan/OpenGL paths. Palette,
  scrolling, masks, transparency and layer order retain their existing rules.
- Extract and restore the Model 1 CPUs once per scheduler call, preserving
  the 64-clock emulation quantum, interrupt handling and restoration on faults.
- Advance the sound UART to its existing clock edges without per-clock loop
  overhead; retain event order and serialized state.
- Reduce polygon allocation/sorting and select the required lighting parameter
  directly, preserving stable depth order and clipping.
- Cache derived YM3438 operator parameters outside serialized state, rebuilding
  them after writes, reset and state restoration.

The retained final C3b build completed the same native Batocera Virtua Racing
3,750-frame replay in 25.877 seconds versus 64.543 seconds for the pre-change
baseline: **59.91% less elapsed time**, approximately **2.49× replay throughput**.
The three video and Save RAM checkpoints match byte for byte. This is a matched,
bounded replay result, not minimum gameplay FPS or a universal speedup claim.
Individual candidate percentages must not be added. The tested idle sound-CPU
batching candidate C4 was reverted because it did not improve performance.

## Packages And Verification

Native GitHub jobs build, test and package Linux x86_64/ARM64, macOS Apple
Silicon/Intel and Windows x86_64 GNU before publication. Each ZIP includes the
public Model 1 core and `.info`, source/build information, installation guide,
licenses and internal checksums; release SHA256SUMS covers all five archives.
No ROMs, personal settings, saves or generated diagnostics are distributed.

The preceding optimization campaign checked nine Model 1 sets plus Sega
NetMerc in both City Workaround modes for video, PCM, Save RAM, state and
continuation equality, with Software/OpenGL/Vulkan evidence on macOS/Batocera.
GitHub release gates establish native build/ABI/package behavior on Windows;
no Windows gameplay or new physical-controller acceptance is claimed.
See `docs/LIBRETRO_MODEL1_PERFORMANCE.md` for exact comparisons and limits.

Machine Save State format remains 5, and Save RAM is unchanged. Sega NetMerc
remains experimental; Save States are unavailable while a linked COMM board
is fitted. Public metadata and the local Development installation retain their
separate names. Libretro ecosystem registration remains pending review.
